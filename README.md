## 🌟 What is TravelLog?

**TravelLog** is a personal travel companion web app that helps you plan trips, track expenses, build day-by-day itineraries, view places on a map, convert currencies, and maintain a travel bucket list — all with a beautiful beach-themed UI that changes with the time of day!

---

## ✨ Features

### 🏖️ Dynamic Beach Theme
- **🌅 Morning (5am-12pm)** — Warm sunrise gradient (orange, pink, gold)
- **☀️ Afternoon (12pm-5pm)** — Bright beach (sky blue, ocean teal)
- **🌇 Evening (5pm-9pm)** — Sunset (deep red, purple, magenta)
- **🌙 Night (9pm-5am)** — Moonlit ocean (dark navy, silver blue)
- Manual dark mode toggle available

### ✈️ Trip Planning
- Create trips with name, destination, dates
- Set budget with multiple currency options
- Choose trip type (Beach, Mountain, City, Heritage, Nature, etc.)
- Add notes for each trip
- View trip status (Upcoming, Ongoing, Completed)
- Budget progress bar with color indicators

### 📅 Day-by-Day Itinerary
- Auto-generated day cards based on trip dates
- Add activities for each day
- Check off completed activities
- Add extra days as needed
- Delete activities

### 💰 Expense Tracker
- Log expenses by category:
  - 🍔 Food
  - 🏨 Hotel
  - 🚗 Transport
  - 🎟️ Tickets
  - 🛍️ Shopping
  - ⛽ Fuel
  - 💊 Medical
  - 📦 Other
- Category-wise summary cards
- Visual bar chart of spending
- Track budget vs actual spending
- Delete individual expenses

### 🗺️ Interactive Map
- World map showing all trip locations
- Auto-geocoding of destinations
- Clickable markers with trip info
- Powered by Leaflet + OpenStreetMap
- List view of all places visited

### 💱 Currency Converter
- 12 currencies supported:
  - 🇮🇳 INR, 🇺🇸 USD, 🇪🇺 EUR, 🇬🇧 GBP
  - 🇯🇵 JPY, 🇦🇺 AUD, 🇨🇦 CAD, 🇹🇭 THB
  - 🇸🇬 SGD, 🇦🇪 AED, 🇲🇾 MYR, 🇱🇰 LKR
- Live exchange rates (with offline fallback)
- Swap currencies button
- Quick reference table vs INR

### 🎯 Bucket List
- Add dream destinations
- Write why you want to visit
- Check off places you've been
- Delete items

### 👋 Personalized Greeting
- Time-based greeting with travel-themed messages
- Morning: "A perfect day for an adventure!"
- Afternoon: "Where will the sun take you today?"
- Evening: "Golden hour — time to explore!"
- Night: "Dream of your next destination!"
